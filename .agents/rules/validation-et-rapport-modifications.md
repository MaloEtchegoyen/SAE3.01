# Demande préalable et rapport de modifications

## Avant toute modification de code existant
- **Demande de validation obligatoire** : avant d'éditer, remplacer ou supprimer du code existant dans un fichier, présenter à l'utilisateur :
  1. Le ou les fichiers concernés.
  2. La nature exacte des changements envisagés et la justification technique/métier.
  3. L'impact potentiel sur le reste de l'application.
- **Attendre l'accord explicite** de l'utilisateur avant d'exécuter la modification du code existant.

## Après les modifications
- **Rapport de modifications obligatoire** : une fois les changements effectués, fournir un résumé clair et détaillé comprenant :
  1. La liste des fichiers, et leur chemin d'accés, modifiés, créés ou supprimés.
  2. Le détail des modifications apportées (avec références de fichiers et lignes si pertinent).
  3. Les vérifications ou tests réalisés (par exemple respect du MVC, non-régression, vérification de syntaxe).
  4. Les éventuels points d'attention ou étapes suivantes recommandées.
  5. Les éventuels impact potentiel sur le reste de l'application.
